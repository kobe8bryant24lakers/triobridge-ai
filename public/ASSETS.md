# Asset provenance

`icon.svg` is original, code-authored geometric artwork for TrioBridge AI. It depicts three connected arches in the application's green palette; it contains no third-party artwork.

`icon-32.png` and `icon-80.png` are rasterizations of `icon.svg` using macOS `sips`, provided because Office manifest icon URLs require raster assets. UI icons are from the ISC-licensed `lucide-react` package. The application uses system fonts; it does not fetch remote fonts or analytics.
