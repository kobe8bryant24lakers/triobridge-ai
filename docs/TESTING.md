## PowerPoint for Mac 实机验证

2026-11-20，在 macOS 26.3.1 和 PowerPoint 16.114.4（16.114.26110224）上完成以下操作。测试使用单独的本地演示文稿和仅监听回环地址的模拟模型服务。

| 操作             | 实机结果                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 安装并打开加载项 | 将 XML 清单安装到 PowerPoint 的 `wef` 目录，将 localhost HTTPS 证书加入用户登录钥匙串。打开带加载项引用的测试文件后，出现「PowerPoint 工作台」。 |
| 读取文字         | 在第 1 页文本框内全选测试文字，点击「读取选区」，读回完整文案。                                                                                  |
| 改写并替换选区   | 检查预览和确认框后写入。保存的第 1 页包含改写后的完整句子。                                                                                      |
| 创建幻灯片       | 预览两页大纲并确认后，PowerPoint 从 1 页变为 3 页。检查保存文件中的文字，确认第 2、3 页分别包含预期标题和要点。                                  |

另在同一任务窗格内向 OpenAI 官方 API 发送简短连接测试。`gpt-4.1-mini` 和 `gpt-6.2-sol` 均返回成功。随后用 `gpt-6.2-sol` 和独立的示例文件验证了以下功能。

- **改写文案。** 插件读取第 1 页中选中的功能介绍，模型将原文改写为一句话。点击「返回检查」后再次打开确认框，原文仍然完整。点击「确认写入」并保存后，在幻灯片 XML 中读到了改写后的文案。
- **整理要点。** 实测发现非翻译任务也附带了默认翻译语言「英语」。修正后用相同中文段落和相同要求重新生成，得到中文标题和三条中文要点。确认写入并保存后，文件保留了各条要点的换行。
- **选区保护。** 生成预览后切换到另一页并选中不同文字，插件提示目标内容或选区已经变化，拒绝替换。检查保存文件确认，第 2、3 页的内容与测试前一致。
- **生成大纲并建页。** 在含原生表格、流程图和图表的八页主稿中，用一段虚构的编辑部周报生成两页大纲。核对 12、9、3 三个数字和两项复核安排后，确认建页，保存文件。原有八页文字、两张表和图表工作簿完整保留。两张新页的标题和四条要点与预览一致，十页便携成品也已在 PowerPoint 中重新打开。

此次实机记录覆盖上述 Mac 版本的加载与读写。Windows、其他 Office 版本和各授权类型的结果仍需分别验证。

模型协议测试覆盖 URL、鉴权、空响应、非法 JSON、截断输出、HTTP 错误、超时与取消；配置测试覆盖密钥生命周期、存储失败、无密钥导入导出；结果测试覆盖公式和大纲校验。

模拟 Office 测试覆盖 API 能力降级、原选区保护、单单元格写入与变化检查。浏览器测试覆盖三应用工作流、确认 / 取消、结果编辑、网络错误与窄窗格布局。本机代理通过 HTTP 集成测试验证固定上游、来源与路径限制。

这些测试不读取真实 API Key 或真实文档，也不等同于真实 Office 客户端验收。
