本轮将已有的本机共享功能封装为自带运行环境的安装包。下列结果针对安装包候选版本；此前真实模型和复杂文档的结果仍单独保留，不替代新安装包的原生 Office 加载验收。

| 本地 API | 真实 TCP / HTTP 请求覆盖带密钥和无密钥的连接并保存、完整端点、后续生成；端口拒绝连接时不保存拟提交的密钥。响应为合成固定回包，用于验证传输与错误处理 |

Windows 自动化仅替换了需要人工批准的“当前用户根证书信任”边界；所有 HTTPS 请求仍验证实际生成的证书，没有关闭 TLS 验证。证书确认、UAC 交互、Windows 桌面 Office 加载和不同授权版本由发布后人工验收，不能由 CI 结果推定通过。

Windows ARM64 的首轮测试发现首次服务启动超过 30 秒，导致安装器过早回退。诊断显示计划任务仍在运行、服务随后已正常监听；Windows 启动等待上限调整为两分钟，持续验证实际 HTTPS 与安装身份，修复后的完整生命周期通过。未删除失败升级场景或降低成功条件。

Mac 最新候选包已从 Finder 双击完成升级，系统证书校验与安装身份对应的 HTTPS 健康检查通过；三个私有清单均写入，升级前后的模型元数据与本机能力凭证逐字节一致。Word、Excel、PowerPoint 完全退出后，分别打开独立副本，均加载本机共享工作台并显示原有当前模型。

新安装包的真实模型验收仍未通过：原生 Word 使用已存密钥执行“连接并保存”后出现本机共享服务响应超时；系统 SecurityAgent 存在，但电脑工具禁止访问该应用，无法据此确认或处理可能的钥匙串提示。正在等待本机用户检查系统窗口。没有将旧版真实模型结果或三应用成功加载计为本轮生成通过，也没有发布 v0.4.0。

另有 Windows 现场反馈：共享文件夹和加载项仅在 PowerPoint 可见，Word / Excel 完全退出重开后仍不可见。已重新下载当前在线安装包，确认其清单包含 `Document`、`Workbook`、`Presentation` 三个宿主；这只能排除清单漏声明，不能排除应用内目录状态、版本或策略问题。安装器新增运行中宿主检查及只读 `Diagnose.cmd`，现场根因和 Word / Excel 可见性仍待确认，未记录为已修复。Windows x64 / ARM64 的新生命周期检查均已通过：用独立的同会话测试进程模拟 Word 进程名，验证安装拒绝且不关闭它、服务重启仍可执行；诊断实际创建的目录、注册表和清单，确认三个宿主声明且报告不含密钥或用户路径。模拟进程不是桌面 Office。

## 真实模型与本机共享最终验收（2026-11-21 至 2026-11-23）

已使用验收环境配置的 OpenAI 模型，在原生 Mac Word、Excel、PowerPoint 内实际请求模型、检查预览、写入文档、保存并重开。数据均为合成业务案例；真实调用与早期固定回包测试分别记录。真实请求使用原有 `https://api.openai.com/v1`，没有替换为模拟服务。

### 调用证据与用量

`requests.jsonl` 共 21 条审计请求：18 次成功（13 次业务生成、5 次连接测试），2 次配置录入阶段的 401，1 次主动取消。成功响应累计返回 **14,930 tokens**，保留请求时间、宿主、请求与返回模型名、completion ID、usage 和合成请求/回复。两个真实模型为 `gpt-6.2-sol` 和 `gpt-4.1-mini`，后者返回版本 `gpt-4.1-mini-2025-04-14`。

这不是账单总额：取消请求和 401 没有返回 usage，不能算作零；最早一次 PowerPoint 连接在启用审计前完成，最终正式构建的 Word 连接在关闭审计后完成，也未包含在上述数量与 token 合计中。两次 401 来自原生密码字段自动化录入未提交，改用粘贴后连接和全部业务调用成功。取消后再次生成成功，文件未被额外改写。

2. **Word 报告污染原文段落样式。** 直接在原段落末尾 `insertHtml` 会合并标题和原文。改为在确认范围后创建新段落，仅在新段落内替换 HTML，并在确认文案中说明位置。原文格式与原生标题、表格均复验通过。参考 [Word Range.insertParagraph](https://learn.microsoft.com/en-us/javascript/api/word/word.range?view=word-js-preview#word-word-range-insertparagraph-member(1))。
3. **PowerPoint 密集中文行距过紧。** 先按文字宽度、换行及页面可用空间选择保守字号，再保留 Office 自动适配处理真实字体度量。该估算不是排版引擎，密集页仍会提示拆页；本次压力样例在原生导出中无缩字或缩行距。
4. **侧栏页码换行。** 页码使用固定的两字符宽度且不收缩，正文允许在剩余宽度换行，已在真实 PowerPoint 侧栏复核。
