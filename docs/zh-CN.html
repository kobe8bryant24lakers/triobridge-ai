Word

先在浏览器里体验完整流程

无需 Office 或密钥即可使用固定演示样例。

下载、双击，再打开 Office

快速安装包自动放好清单。无需 Node.js、本机服务或开发证书，连接模型时选择服务并填入 API Key 即可。

为 Word、Excel、PowerPoint 一起安装

Mac：解压后双击 Install.command。
Windows：先解压整个文件夹，再双击 Install.cmd。

下载 Mac 安装包下载 Windows 安装包

个人测试包，尚未签名，首次运行需系统确认；Windows 需管理员权限，自动安装仍待实机验证。遇到系统拦截或安装失败，可展开下方对应系统的说明。

  1. 运行对应安装包

    安装程序自动处理清单位置；Windows 同时添加当前用户的受信任目录。需要已安装 Microsoft Office，且允许使用加载项。

  2. 重新打开 Office，添加三桥 AI

    先保存文档并完全退出 Office。重开后在主页 → 加载项选择三桥 AI（在线版）；Windows 进入高级 / 更多加载项 → 共享文件夹后添加。

  3. 选择模型服务，填入密钥

    在“模型设置”选择服务、粘贴 API Key，点击连接并保存。服务地址和默认模型自动填写，仍可在高级设置中调整。使用时需要联网。

移除安装文件：运行包内的 Uninstall.command 或 Uninstall.cmd。模型配置和密钥需在插件内删除。若安装包不可用，可下载 XML 清单并按下方手动安装。

Mac 手动安装安装包不可用时展开

如果系统阻止安装包运行，可在“系统设置 → 隐私与安全性”按提示允许，或直接使用以下手动安装步骤。组织策略可能禁止旁加载。

  1. 下载线上清单

    保存上方的 XML 文件，保留 .xml 扩展名。不要把浏览器展示的 XML 页面另存为 HTML。

  2. 复制到对应应用的目录

    打开 Finder，按 ⌘ ⇧ G，粘贴下列目录。若 wef 不存在，先打开对应的 Documents 目录，再新建名为 wef 的文件夹。

    Word
    ~/Library/Containers/com.microsoft.Word/Data/Documents/wef/
    Excel
    ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/
    PowerPoint
    ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef/

    把下载的清单复制到要使用的应用目录中。需要三种应用时，分别复制一份。

  3. 重新打开 Office 并选择加载项

    完全退出后重新打开对应应用，打开一份文档。在主页 → 加载项中选择 TrioBridge AI · 三桥 AI（在线版）。部分版本入口位于“插入 → 我的加载项”。

微软官方 Mac 旁加载说明
Windows 手动安装共享目录与故障处理

自动安装会请求管理员权限，仅向当前账号开放共享目录。失败时请确认 Windows 文件共享服务可用，或联系管理员检查组织策略；安装程序不会自动修改防火墙或组织策略。手动安装步骤如下。

  1. 为清单创建专用文件夹

    例如创建 C:\OfficeAddins\TrioBridge，把下载的线上 XML 清单放入其中。

  2. 共享文件夹并记录网络路径

    右键文件夹，打开属性 → 共享 → 共享，只向需要使用的账号授予所需读写权限。记录 Windows 显示的完整网络路径，例如 \\YOUR-PC\TrioBridge。这里的计算机名和共享名需要替换为你的实际值。

  3. 在 Office 中信任该目录

    打开文件 → 选项 → 信任中心 → 信任中心设置 → 受信任的加载项目录。填写刚才的网络路径，点击“添加目录”，勾选在菜单中显示，然后确定。

  4. 重新打开 Office 并添加插件

    关闭后重新打开应用。在主页 → 加载项 → 高级中打开共享文件夹，选择 TrioBridge AI · 三桥 AI（在线版）并添加。部分版本可从“插入 → 我的加载项 → 共享文件夹”进入。

共享目录内放的是清单，工作台仍由线上 HTTPS 站点提供。这里的共享文件夹旁加载用于个人或开发测试，不是企业生产分发渠道。组织部署请由管理员选择受支持的分发方式。

第一次使用

先用一小段内容，
走完一次流程

浏览器演示使用模拟文档。在 Office 中，工作台会显示当前宿主支持的读取和写回操作。

打开工作台

  1. 连接并保存模型

    打开“模型设置”，选择服务、粘贴 API Key，点击“连接并保存”。其他模型与高级设置。

  2. 提供参考内容

    在 Office 中选中内容，再点击“读取选区”，也可以直接粘贴。PowerPoint 需要先进入文字编辑状态。

  3. 选择任务并生成预览

    补充希望修改或生成的具体要求。等待过程中可停止请求，文档此时不会改变。

  4. 检查后再写入

    需要时先编辑结果。点击写入操作后，核对位置与前后内容，再确认。没有写回能力时仍可复制使用。

选好服务，填入密钥

DeepSeek、OpenAI、通义千问（北京）提供预设地址和模型，点击“连接并保存”即可测试并保存。使用其他兼容服务或本地模型时，选择“自定义 / 本地模型”。

模型服务
常用服务自动填写名称、地址与默认模型，按你持有的 API Key 选择。千问预设使用北京地域；其他地域可在高级设置中修改地址。
API Key
按服务要求填写。无需鉴权的本地服务可以留空。
高级设置
需要时修改服务名称、完整接口地址、模型 ID 或超时。更换服务地址会清空原密钥；离线准备配置可选择“仅保存配置”。

连接测试会发送一句简短测试文字，可能产生少量模型调用费用。应用支持设置超时和取消请求。

连接失败时，优先检查这些条件

线上模型需要 HTTPS 和跨域许可

远程服务地址需要使用 HTTPS。模型服务还需允许来自本页域名的跨域请求（CORS）。GitHub Pages 默认部署的来源为：

https://kobe8bryant24lakers.github.io

来源只包含协议和域名，不包含 /triobridge-ai/ 路径。服务需正确处理 OPTIONS 预检，并允许 POST 请求及 Authorization、Content-Type 请求头。

确认接口类型与地址路径

支持 OpenAI 兼容的 Chat Completions 接口，也接受完整的 /chat/completions 地址。仅提供 Responses 或 Anthropic 原生接口的服务不能直接使用。当前不支持流式响应。

本地模型与代理需要自托管

GitHub Pages 只托管静态页面，不提供 /model-proxy/v1 代理。线上 HTTPS 页面连接 HTTP 本地模型，可能受到浏览器的混合内容或私有网络限制。

需要固定目标的本机代理时，请按仓库的自托管说明运行本机服务。该代理路径只在对应的自托管服务中可用，不能直接填给线上版。

各应用的写回边界
  • Word：以纯文本写回，不保证保留原选区内部的全部富文本样式。
  • Excel：每次写入一个公式单元格，不自动批量写公式或创建图表。
  • PowerPoint：自动建页需要 PowerPointApi 1.4。生成的是基础标题和要点文本框，最多 12 页，不自动生成主题、图片或图表。能力不足时仍可生成并复制大纲。
  • 安全写回：若宿主无法追踪选区变化，会限制自动替换并提供复制。建页出错时可能留下部分新增页，请检查后使用 Office 撤销。

实际可用功能还受内置浏览器版本、账号和组织策略影响。更多说明见仓库兼容性文档。

遇到问题

常见问题

浏览器演示会调用真实 AI 吗？

选择“演示模型”时使用固定样例，不会调用模型，也不会修改 Office 文件。演示页面同样支持你配置真实模型，这时会把可见输入实际发送给所选服务，但文档仍是浏览器中的模拟文档。

下载清单后，为什么还看不到加载项？

下载不会自动完成安装。请按对应系统的安装步骤将 XML 放入正确目录，然后完全退出并重新打开 Office。Windows 还需添加受信任的共享目录并勾选“在菜单中显示”。组织策略禁用加载项时，需要联系管理员。

模型生成成功，为什么没有自动写入？

生成只产生预览。你需要选择写回操作并再次确认。如果当前宿主、选区或任务不支持自动写回，工作台会提供复制方式。Excel 的分析和解释本来就是供复制使用的文字结果。

插件更新后，需要重新安装吗？

托管工作台更新后，重新打开加载项即可加载新版本。如果 Release 说明要求更新清单，请下载新的 XML，替换原目录中的清单并重启 Office。组织分发的版本请遵循管理员安排。
