三种应用使用同一套模型配置方式，任务跟随当前内容变化。

Word

把文字整理成下一稿

  • 改写润色让表达更清楚，保留原意
  • 提炼摘要把长内容整理成重点
  • 翻译文本保留术语、数字与结构
  • 起草内容根据具体要求写出第一稿
  • 结构化报告编辑章节、要点和表格后插入

检查后写回核对排版后替换选区或插入到光标处。Markdown 标题、列表和表格可在 Word 中继续编辑。

Excel

理解表格，让计算更有把握

  • 生成公式描述目标，得到可检查的公式
  • 解释公式看懂函数、引用与计算过程
  • 表格问答围绕选中的数据提出问题
  • 分析建议查看趋势、异常与下一步方向
  • 创建数据表新建含公式和列格式的工作表

核对目标后写入写入单个公式，或在独立新表创建数据与公式。分析与解释可复制。

PowerPoint

从素材生成整稿，也能修改现有页面

  • 素材生成选择本地目录，生成可编辑整套 PPT
  • 现有页面编辑调整整稿或单页背景、套用样式、插页和拆页
  • 原生数据图表同步刷新原图表和内嵌 Excel 工作簿
  • 批量排版工具逐项预览改动，复用配方，检查批注和版面问题

预览后应用检查改动并写回所选对象，或另存可编辑的 PPTX。

下载与安装

按电脑的系统和芯片选择安装包。工作台默认使用简体中文，可从独立窗口或 Office 侧边栏中三桥 AI 标志旁的语言菜单切换为 English。

Windows

在“设置 → 系统 → 系统信息”查看系统类型。常见 Intel 和 AMD 电脑选择 x64。

Windows x64 Windows ARM64
安装步骤

保存文档，退出三款 Office，完整解压 ZIP，双击 Install.cmd。用同一 Windows 账户以普通权限打开文档，在“三桥 AI”功能区选择“打开侧边栏”或“打开独立窗口”。

Mac

在苹果菜单的“关于本机”查看芯片。M 系列芯片选 Apple 芯片，Intel 芯片选 Intel。

Mac · Apple 芯片 Mac · Intel
安装步骤

解压 ZIP，双击 Install.command。在 Word、Excel 或 PowerPoint 的应用菜单中选择“服务 → 打开三桥 AI”。首次读写时，macOS 可能请求允许控制对应应用。要启用内嵌侧栏，退出 Office，运行 Enable-Embedded-Taskpane.command 并按提示信任本机证书。重开 Office，从“我的加载项”选择名称含“三桥 AI”和“本机共享”的加载项。

从选区到结果

下载图解使用指南 PowerPoint · 44 页 · 简体中文

  1. 连接模型

    打开模型设置，选择云端服务或本机 API。使用本机 API 时，先启动自己的模型程序，填写它提供的地址（例如 http://127.0.0.1:8001/v1）和模型 ID。 按服务支持的接口选择 OpenAI（Chat Completions）或 Claude（Anthropic Messages），再点击“连接并保存”。

  2. 选择内容

    读取 Word 或 Excel 选区，也可在 PowerPoint 选择素材目录、当前页面或整套演示稿。

  3. 查看预览

    生成后检查文字、公式、表格或页面。模型只在你发起请求时接收所选内容。

  4. 确认写入

    核对目标文档和位置后写入。选区变化时重新读取。

系统与模型

桌面 Office
具备所需能力的永久授权版 Office 也可使用。 Windows 的两个入口都在“三桥 AI”功能区。Mac 可从“服务”菜单打开独立窗口，或从“我的加载项”打开已启用的内嵌侧栏。
安装与权限
独立窗口和 Windows 侧栏从安装包加载界面。若 Windows 缺少 WebView2，可运行 ZIP 内的离线安装程序。Mac 内嵌侧栏使用本机 HTTPS 服务，需联网从微软加载 Office.js。
同机复用
Word、Excel 和 PowerPoint 共用当前账户的多模型配置，密钥保存在系统凭据库。使用本机 API 时，请先确认原有模型程序正在运行。
