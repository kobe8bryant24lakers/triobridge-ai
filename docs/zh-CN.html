无需 Office 或密钥即可使用固定演示样例。

本机共享版 · v0.5.2

安装一次，三款 Office 共用模型

安装包自带运行环境，自动配置本机服务、证书和加载项入口。无需安装 Node.js 或输入命令，支持云端模型及本地 HTTP API。

Windows 本机共享版

普通 Intel / AMD 电脑选择 x64；搭载 Snapdragon 等 ARM 处理器的电脑选择 ARM64。

下载 Windows x64下载 Windows ARM64

Mac 本机共享版

搭载 Apple M 系列芯片选择 Apple 芯片版；较早的 Intel Mac 选择 Intel 版。

下载 Mac Apple 芯片版下载 Mac Intel 版

安装包尚未签名。首次运行可能需要系统确认；证书信任由系统提示，Windows 创建当前账号专用共享目录时会请求管理员授权。需要已安装 Office，且组织策略允许加载项。Mac 首次使用或升级后可能请求钥匙串访问，请在系统窗口确认后重试。Windows 原生 Office 验收仍待完成。

  1. 解压完整文件夹，双击 Install

    先保存文档并完全退出 Word、Excel、PowerPoint。Windows 打开 Install.cmd，Mac 打开 Install.command，按系统提示完成安装。服务随当前账号登录启动，安装完成后可以关闭安装窗口。

  2. 重开 Office，选择“本机共享”

    在每个应用的主页 → 加载项分别添加三桥 AI（本机共享）；Windows 从高级 / 更多加载项 → 共享文件夹添加。模型设置页应显示本机共享。

  3. 配置模型，三个应用复用

    在任一应用新增模型并连接并保存。可填写 http://127.0.0.1:8001/v1 这样的本地地址；无需鉴权时选择不使用密钥。模型列表、默认模型与系统安全存储中的密钥供同一账号下的三个应用复用。

Windows 的“共享文件夹”只是加载项安装入口。请确认选择的是本机共享，旧的在线版仍使用各应用独立配置。

升级或修复：下载新版并再次运行 Install。Restart 重启服务；Uninstall 卸载服务、入口和本次安装的证书，保留模型配置与密钥。本机安装与故障处理 · 更新记录

在线版与手动旁加载各应用独立配置，不安装本机服务

在线版从网站加载工作台，模型服务需要允许浏览器跨域访问。需要访问本地 HTTP API 或跨应用复用模型时，请使用上方本机共享版。

    保存上方的 XML 文件，保留 .xml 扩展名。不要把浏览器展示的 XML 页面另存为 HTML。

    把下载的清单复制到要使用的应用目录中。需要三种应用时，分别复制一份。

    完全退出后重新打开对应应用，打开一份文档。在主页 → 加载项中选择 TrioBridge AI · 三桥 AI（在线版）。部分版本入口位于“插入 → 我的加载项”。

Windows 手动安装共享目录与故障处理

自动安装会请求管理员权限，仅向当前账号开放共享目录。失败时请确认 Windows 文件共享服务可用，或联系管理员检查组织策略；安装程序不会自动修改防火墙或组织策略。手动安装步骤如下。

  1. 为清单创建专用文件夹

    例如创建 C:\OfficeAddins\TrioBridge，把下载的线上 XML 清单放入其中。

  2. 共享文件夹并记录网络路径

    右键文件夹，打开属性 → 共享 → 共享，只向需要使用的账号授予所需读写权限。记录 Windows 显示的完整网络路径，例如 \\YOUR-PC\TrioBridge。这里的计算机名和共享名需要替换为你的实际值。

  3. 在 Office 中信任该目录

    打开文件 → 选项 → 信任中心 → 信任中心设置 → 受信任的加载项目录。填写刚才的网络路径，点击“添加目录”，勾选在菜单中显示，然后确定。

  4. 重新打开 Office 并添加插件

    关闭后重新打开应用。在主页 → 加载项 → 高级中打开共享文件夹，选择 TrioBridge AI · 三桥 AI（在线版）并添加。部分版本可从“插入 → 我的加载项 → 共享文件夹”进入。

共享目录内放的是清单，工作台仍由线上 HTTPS 站点提供。这里的共享文件夹旁加载用于个人或开发测试，不是企业生产分发渠道。组织部署请由管理员选择受支持的分发方式。

第一次使用

先用一小段内容，
走完一次流程

浏览器演示使用模拟文档。在 Office 中，工作台会显示当前宿主支持的读取和写回操作。

打开工作台

  1. 连接并保存模型

    打开“模型设置”，选择服务、粘贴 API Key，点击“连接并保存”。其他模型与高级设置。

  2. 提供参考内容

    在 Office 中选中内容，再点击“读取选区”，也可以直接粘贴。PowerPoint 需要先进入文字编辑状态。

  3. 选择任务并生成预览

    补充希望修改或生成的具体要求。等待过程中可停止请求，文档此时不会改变。

  4. 检查后再写入

    需要时先编辑结果。点击写入操作后，核对位置与前后内容，再确认。没有写回能力时仍可复制使用。

选好服务，填入密钥

DeepSeek、OpenAI、通义千问（北京）提供预设地址和模型，点击“连接并保存”即可测试并保存。使用其他兼容服务或本地模型时，选择“自定义 / 本地模型”。

模型服务
常用服务自动填写名称、地址与默认模型，按你持有的 API Key 选择。千问预设使用北京地域；其他地域可在高级设置中修改地址。
API Key
按服务要求填写。无需鉴权时，本机共享版选择“不使用密钥”；在线版可留空。
高级设置
需要时修改服务名称、完整接口地址、模型 ID 或超时。更换服务地址后需重新填写密钥或明确选择不使用密钥，不会自动携带旧密钥；离线准备配置可选择“仅保存配置”。

连接测试会发送一句简短测试文字，可能产生少量模型调用费用。应用支持设置超时和取消请求。

连接失败时，优先检查这些条件

在线版需要模型 API 允许跨域

两种版本的远程服务地址都需要 HTTPS。只有在线版需要模型服务允许来自本页域名的跨域请求（CORS）。GitHub Pages 默认部署的来源为：

https://kobe8bryant24lakers.github.io

来源只包含协议和域名，不包含 /triobridge-ai/ 路径。服务需正确处理 OPTIONS 预检，并允许 POST 请求及 Authorization、Content-Type 请求头。

确认接口类型与地址路径

支持 OpenAI 兼容的 Chat Completions 接口，也接受完整的 /chat/completions 地址。仅提供 Responses 或 Anthropic 原生接口的服务不能直接使用。当前不支持流式响应。

使用本机共享版连接本地 HTTP API

安装本机共享包后，可直接填写 http://127.0.0.1:8001/v1 等地址。本机服务负责调用，无需模型 API 开放浏览器 CORS。模型 API 必须在这台电脑运行；容器中的 API 需要映射端口。

若报错仍提到 CORS，请确认选择的是“本机共享”加载项。查看连接排查

各应用的写回边界
  • Word：纯文本替换不保证保留选区内部样式；包含表格、图片等对象的选区限制直接替换。结构化报告支持插入章节、要点和表格，最终分页由 Word 决定。
  • Excel：支持单公式写入；新建格式化数据表需要 ExcelApi 1.2，含表头最多 2,000 格，写入后检查公式错误。不自动创建图表。
  • PowerPoint：自动建页需要 PowerPointApi 1.4。生成的是基础标题和要点文本框，最多 12 页，不自动生成主题、图片或图表。能力不足时仍可生成并复制大纲。
  • 写入保护：若宿主无法追踪选区变化，会限制自动替换并提供复制。建页或建表失败可能留下部分内容，请按提示检查并恢复。

新增报告、数据表和建页已在本机 Mac Office 完成主要流程验收，覆盖排版、公式重算与原文保留。Windows 及其他 Office 版本仍需独立实机验收。实际可用功能还受内置浏览器版本、账号和组织策略影响。更多说明见仓库兼容性文档。

遇到问题

常见问题

浏览器演示会调用真实 AI 吗？

选择“演示模型”时使用固定样例，不会调用模型，也不会修改 Office 文件。演示页面同样支持你配置真实模型，这时会把可见输入实际发送给所选服务，但文档仍是浏览器中的模拟文档。

下载清单后，为什么还看不到加载项？

下载不会自动完成安装。请按对应系统的安装步骤将 XML 放入正确目录，然后完全退出并重新打开 Office。Windows 还需添加受信任的共享目录并勾选“在菜单中显示”。组织策略禁用加载项时，需要联系管理员。

Windows 安装停在第 3 步，应该看哪里？

第 3 步会启动登录任务、验证 localhost 的 3000 端口并读取共享配置。窗口会显示当前检查项和等待时间。若显示 MODEL_STORAGE，双击 Diagnose.cmd，查看 localService.lastStartup.storageDetail 中的具体原因。报告还会检查文件所有权和权限。下载 Windows 只读诊断工具

Windows 只有一个应用能看到加载项？

三个应用需各自在“主页 → 加载项 → 高级 / 更多加载项 → 共享文件夹”中添加入口。重开后仍没有“共享文件夹”时，核对该应用的“受信任的加载项目录”与可用应用是否一致。运行包内 Diagnose.cmd 可只读检查版本、目录可达性和三应用声明，不读取模型密钥或文档。查看具体排查步骤

模型生成成功，为什么没有自动写入？

生成只产生预览。你需要选择写回操作并再次确认。如果当前宿主、选区或任务不支持自动写回，工作台会提供复制方式。Excel 的分析和解释本来就是供复制使用的文字结果。

插件更新后，需要重新安装吗？

本机共享版下载新版安装包并再次运行 Install，配置与密钥会保留。在线工作台更新后，重新打开加载项即可加载新版本。如果 Release 说明要求更新清单，请下载新的 XML，替换原目录中的清单并重启 Office。组织分发的版本请遵循管理员安排。
