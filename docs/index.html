Local shared edition · v0.5.1

One setup for all three Office apps

The package includes its runtime and sets up the local service, certificate, and add-in entries. No Node.js installation or commands required. Connect cloud models or a local HTTP API.

Local shared edition for Windows

Choose x64 for Intel / AMD PCs, or ARM64 for Snapdragon and other ARM PCs.

Local shared edition for Mac

Choose Apple silicon for M-series chips, or Intel for an Intel Mac.

Download Mac Apple siliconDownload Mac Intel

Packages are unsigned and may require system confirmation. Approve the OS certificate prompt; Windows also requests administrator authorization for a private catalog share. Office must be installed and organizational policies must allow add-ins. Mac may request Keychain access on first use or after an upgrade; complete the system prompt and retry. Native Windows Office acceptance remains pending.

  1. Extract the entire folder and open Install

    Save documents and completely close Word, Excel and PowerPoint first. Double-click Install.cmd on Windows or Install.command on Mac and follow the system prompts. The service starts when you sign in; close the installation window once setup finishes.

  2. Reopen Office and select the local shared entry

    Add 三桥 AI（本机共享） separately in each app under Home → Add-ins. On Windows, use Advanced / More Add-ins → Shared Folder. Model settings should show 本机共享 (local shared).

  3. Configure models once

    Add a model in any app and choose Connect and save (连接并保存). Local URLs such as http://127.0.0.1:8001/v1 are supported; choose No key (不使用密钥) when authentication is unnecessary. All three apps share profiles, the default model, and OS-stored keys under the same account.

Windows “Shared Folder” is an installation catalog. Check that you open the local shared entry; the older hosted edition keeps separate settings in each app.

To upgrade or repair, download the new package and run Install again. Restart restarts the service. Uninstall removes the service, entries, and this installation’s certificate while preserving profiles and keys. Local setup and troubleshooting · Release notes

Manual Windows setupShared folders and troubleshooting

The automatic installer requests administrator privileges and shares the directory only with the current account. If it fails, check that Windows file sharing is available or ask your administrator to review organizational policies. The installer does not change firewall or organizational policies. To install manually, follow these steps.

  1. Create a dedicated folder for the manifest

    For example, create C:\OfficeAddins\TrioBridge and place the downloaded hosted XML manifest inside it.

  2. Share the folder and note its network path

    Right-click the folder and open Properties → Sharing → Share. Grant the required read/write permissions only to accounts that need access. Note the full network path shown by Windows, such as \\YOUR-PC\TrioBridge. Replace the computer and share names with your actual values.

  3. Trust the catalog in Office

    Open File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs. Enter the network path, click Add Catalog, enable Show in Menu, and confirm.

  4. Reopen Office and add the add-in

    Close and reopen the application. Open Shared Folder under Home → Add-ins → Advanced, select TrioBridge AI · 三桥 AI（在线版）, and add it. Some versions use Insert → My Add-ins → Shared Folder.

The shared folder contains the manifest; the workbench is still served by the hosted HTTPS site. Shared-folder sideloading is for personal or development testing, not enterprise production distribution. For organizational deployment, ask your administrator to choose a supported distribution method.

Your first session

Start small.
Try the whole workflow.

The browser demo uses simulated documents. In Office, the workbench shows the reading and writing actions supported by the current host. The workbench interface is currently in Chinese.

Open the workbench

  1. Connect and save a model

    Open Model settings (模型设置), select a provider, paste your API key, and click Connect and save (连接并保存). Other models and advanced settings.

  2. Provide reference content

    Select content in Office, then click Read selection (读取选区), or paste content directly. In PowerPoint, enter text-editing mode first.

  3. Choose a task and generate a preview

    Add specific requirements for the changes or content you want. You can stop the request while waiting; your document remains unchanged.

  4. Review before writing

    Edit the result if needed. Choose a write action, review the destination and before/after content, and confirm. If writing is unavailable, you can still copy the result.

Choose your provider. Add your key.

DeepSeek, OpenAI, and Qwen (Beijing) include preset URLs and models. Click Connect and save (连接并保存) to test and save. For another compatible provider or a local model, choose Custom / local model (自定义 / 本地模型).

Model provider
Choose the provider for your API key. Common providers fill in the name, URL, and default model automatically. The Qwen preset uses the Beijing region; change the URL in advanced settings for other regions.
API Key
Enter a key if your provider requires one. In the local shared edition, choose No key (不使用密钥) for services without authentication; in the hosted edition, leave the field blank.
Advanced settings
Change the provider name, full endpoint URL, model ID, or timeout when needed. Changing the URL requires a new key or an explicit No key choice; an existing key is never sent to a new service automatically. Choose Save configuration only (仅保存配置) to prepare settings offline.

Connection tests send a short message and may incur a small model usage charge. The app supports configurable timeouts and request cancellation.

If a connection fails, check these first

The hosted edition requires model API CORS

Remote provider URLs must use HTTPS in both editions. Only the hosted edition requires the model service to allow cross-origin requests (CORS) from this site. The default GitHub Pages origin is:

https://kobe8bryant24lakers.github.io

The origin includes only the protocol and domain, without the /triobridge-ai/ path. The service must handle OPTIONS preflight requests and allow POST requests with the Authorization and Content-Type headers.

Check the API protocol and URL path

OpenAI-compatible Chat Completions APIs are supported, including complete /chat/completions URLs. Providers offering only Responses or native Anthropic APIs cannot be used directly. Streaming responses are not currently supported.

Connect a local HTTP API with the local shared edition

Install the local shared package and enter your model URL, such as http://127.0.0.1:8001/v1. The installed service calls the API without browser CORS requirements. The model API must be running on the same computer; containers need a published port.

If the error mentions CORS, check that you selected the local shared add-in, not the hosted entry. Connection troubleshooting

Writing capabilities and limitations
  • Word: Plain-text replacement may not preserve formatting within the selection. Direct replacement is restricted for selections containing tables, images, or other objects. Structured reports can insert sections, bullet points, and tables; Word determines final pagination.
  • Excel: Single-formula writing is supported. Creating formatted data tables requires ExcelApi 1.2, with a maximum of 2,000 cells including headers. Formula errors are checked after writing. Charts are not created automatically.
  • PowerPoint: Automatic slide creation requires PowerPointApi 1.4. It creates basic title and bullet-point text boxes, up to 12 slides, without themes, images, or charts. If the required capability is unavailable, outlines can still be generated and copied.
  • Write safeguards: If the host cannot track selection changes, automatic replacement is restricted and copying is offered. Failed slide or worksheet creation may leave partial content; follow the prompts to inspect and recover.

The main report, data table, and slide-creation workflows have passed acceptance testing in local Mac Office, covering layout, formula recalculation, and preservation of original content. Windows and other Office versions still require separate testing on physical machines. Available features also depend on the embedded browser, account, and organizational policies. See the repository compatibility documentation.

Content and credentials

You decide
what gets sent

Model requests go to the service you configure. The add-in does not save documents, generation history, or telemetry. Your model provider’s policies govern how it handles requests.

Read and send on request
You initiate reading and generation separately. Real requests contain only the visible reference content, task, and requirements.
Keys stay in your OS credential store
The local shared edition uses macOS Keychain or Windows Credential Manager. The hosted edition keeps keys for the session by default; choosing Remember stores them in plain text in that app’s local storage.
Profile exports exclude keys
The local shared edition reuses profiles and keys within the same OS account. Exported profiles exclude keys and local installation credentials. Set up credentials again when moving to a different computer.
Review before making changes
Generated results are editable, and the destination and content are shown before writing. You can return to review or copy the result and use it yourself.

Need help?

Frequently asked questions

Does the browser demo call a real AI model?

The Demo model (演示模型) uses fixed samples without calling a model or changing Office files. You can also configure a real model in the demo; visible input is then sent to your selected provider, while the documents remain simulated in the browser.

Why is the add-in missing after I download the manifest?

Downloading the manifest does not install it. Follow the installation steps for your system to place the XML in the correct directory, then quit and reopen Office. On Windows, also add the trusted shared-folder catalog and enable Show in Menu. Contact your administrator if organizational policies disable add-ins.

Windows setup is waiting at step 3. What should I check?

Step 3 starts the sign-in task, verifies HTTPS on localhost port 3000 and reads the shared configuration. The installer shows the current check and elapsed time. If setup rolls back, open Diagnose.cmd and look at localService.lastStartup. Download the read-only Windows diagnostic

Why can only one Office app see the Windows entry?

Add the entry separately in each app under Home → Add-ins → Advanced / More Add-ins → Shared Folder. If the Shared Folder tab is missing after restarting, compare the app’s Trusted Add-in Catalogs settings with the working app. Run Diagnose.cmd in the package to check versions, catalog access and the three manifest hosts; it does not read model keys or documents. Discovery troubleshooting

Why was a successful result not written automatically?

Generation creates a preview only. Choose a write action and confirm it. If the current host, selection, or task does not support automatic writing, the workbench offers copying instead. Excel analyses and explanations are text results intended for copying.

Do I need to reinstall after an update?

For the local shared edition, download the new package and run Install again; profiles and keys are preserved. Reopen the hosted add-in to load an updated online workbench. If release notes require a new manifest, download the new XML, replace the manifest in its original directory, and restart Office. Follow your administrator’s instructions for organizational deployments.
