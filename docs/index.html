Download Mac installerDownload Windows installer

These unsigned packages are for personal testing and require system confirmation on first launch. Windows requires administrator privileges; automatic installation still needs testing on a physical Windows machine. If installation is blocked or fails, expand the instructions for your system below.

  1. Run the installer for your system

    The installer handles the manifest location and, on Windows, adds a trusted catalog for the current user. Microsoft Office must already be installed with add-ins allowed.

  2. Reopen Office and add TrioBridge AI

    Save your documents and quit Office completely. Reopen it and select 三桥 AI（在线版） under Home → Add-ins. On Windows, add it through Advanced / More Add-ins → Shared Folder.

  3. Choose a provider and enter your key

    In Model settings (模型设置), select a provider, paste your API key, and click Connect and save (连接并保存). The provider URL and default model are filled in automatically and can be changed in advanced settings. An internet connection is required.

To remove the installation, run Uninstall.command or Uninstall.cmd from the package. Delete model profiles and keys inside the add-in. If the installer is unavailable, download the XML manifest and follow the manual instructions below.

Manual Windows setupShared folders and troubleshooting

The automatic installer requests administrator privileges and shares the directory only with the current account. If it fails, check that Windows file sharing is available or ask your administrator to review organizational policies. The installer does not change firewall or organizational policies. To install manually, follow these steps.

  1. Create a dedicated folder for the manifest

    For example, create C:\OfficeAddins\TrioBridge and place the downloaded hosted XML manifest inside it.

  2. Share the folder and note its network path

    Right-click the folder and open Properties → Sharing → Share. Grant the required read/write permissions only to accounts that need access. Note the full network path shown by Windows, such as \\YOUR-PC\TrioBridge. Replace the computer and share names with your actual values.

  3. Trust the catalog in Office

    Open File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs. Enter the network path, click Add Catalog, enable Show in Menu, and confirm.

  4. Reopen Office and add the add-in

    Close and reopen the application. Open Shared Folder under Home → Add-ins → Advanced, select TrioBridge AI · 三桥 AI（在线版）, and add it. Some versions use Insert → My Add-ins → Shared Folder.

The shared folder contains the manifest; the workbench is still served by the hosted HTTPS site. Shared-folder sideloading is for personal or development testing, not enterprise production distribution. For organizational deployment, ask your administrator to choose a supported distribution method.

Try the whole workflow.

The browser demo uses simulated documents. In Office, the workbench shows the reading and writing actions supported by the current host. The workbench interface is currently in Chinese.

Open the workbench

  1. Connect and save a model

    Open Model settings (模型设置), select a provider, paste your API key, and click Connect and save (连接并保存). Other models and advanced settings.

  2. Provide reference content

    Select content in Office, then click Read selection (读取选区), or paste content directly. In PowerPoint, enter text-editing mode first.

  3. Choose a task and generate a preview

    Add specific requirements for the changes or content you want. You can stop the request while waiting; your document remains unchanged.

  4. Review before writing

    Edit the result if needed. Choose a write action, review the destination and before/after content, and confirm. If writing is unavailable, you can still copy the result.

Choose your provider. Add your key.

DeepSeek, OpenAI, and Qwen (Beijing) include preset URLs and models. Click Connect and save (连接并保存) to test and save. For another compatible provider or a local model, choose Custom / local model (自定义 / 本地模型).

Model provider
Choose the provider for your API key. Common providers fill in the name, URL, and default model automatically. The Qwen preset uses the Beijing region; change the URL in advanced settings for other regions.
API Key
Enter a key if your provider requires one. Leave it blank for local services that do not require authentication.
Advanced settings
Change the provider name, full endpoint URL, model ID, or timeout when needed. Changing the URL clears the previous key. Choose Save configuration only (仅保存配置) to prepare settings offline.

Connection tests send a short message and may incur a small model usage charge. The app supports configurable timeouts and request cancellation.

If a connection fails, check these first

Hosted models need HTTPS and CORS permission

Remote provider URLs must use HTTPS. The model service must also allow cross-origin requests (CORS) from this site. The default GitHub Pages origin is:

https://kobe8bryant24lakers.github.io

The origin includes only the protocol and domain, without the /triobridge-ai/ path. The service must handle OPTIONS preflight requests and allow POST requests with the Authorization and Content-Type headers.

Check the API protocol and URL path

OpenAI-compatible Chat Completions APIs are supported, including complete /chat/completions URLs. Providers offering only Responses or native Anthropic APIs cannot be used directly. Streaming responses are not currently supported.

Local models and proxies require self-hosting

GitHub Pages hosts static pages and does not provide a /model-proxy/v1 proxy. Connecting from the hosted HTTPS page to an HTTP local model may be blocked by mixed-content or private-network restrictions.

If you need a local proxy with a fixed target, run the local server using the repository’s self-hosting instructions. This proxy path works only on that self-hosted server and cannot be entered directly in the hosted version.

Writing capabilities and limitations
  • Word: Writes plain text and does not guarantee preservation of all rich-text formatting within the original selection.
  • Excel: Writes one formula cell at a time. It does not automatically write formulas in bulk or create charts.
  • PowerPoint: Automatic slide creation requires PowerPointApi 1.4. It creates basic title and bullet-point text boxes, up to 12 slides, without themes, images, or charts. If the required capability is unavailable, outlines can still be generated and copied.
  • Write safeguards: If the host cannot track selection changes, automatic replacement is restricted and copying is offered. Failed slide creation may leave some new slides; inspect them and use Office Undo.

Available features also depend on the embedded browser, account, and organizational policies. See the repository compatibility documentation.

Need help?

Frequently asked questions

Does the browser demo call a real AI model?

The Demo model (演示模型) uses fixed samples without calling a model or changing Office files. You can also configure a real model in the demo; visible input is then sent to your selected provider, while the documents remain simulated in the browser.

Why is the add-in missing after I download the manifest?

Downloading the manifest does not install it. Follow the installation steps for your system to place the XML in the correct directory, then quit and reopen Office. On Windows, also add the trusted shared-folder catalog and enable Show in Menu. Contact your administrator if organizational policies disable add-ins.

Why was a successful result not written automatically?

Generation creates a preview only. Choose a write action and confirm it. If the current host, selection, or task does not support automatic writing, the workbench offers copying instead. Excel analyses and explanations are text results intended for copying.

Do I need to reinstall after an update?

Reopen the add-in to load an updated hosted workbench. If release notes require a new manifest, download the new XML, replace the manifest in its original directory, and restart Office. Follow your administrator’s instructions for organizational deployments.
