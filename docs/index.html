Download and install

Choose your system and processor. The workbench opens the compiled page on your computer. Your configured model can run on this computer or online. The workbench starts in Simplified Chinese. Choose English near the TrioBridge AI logo in either the standalone window or the Office task pane.

Windows

Check System type in Settings → System → About. Intel and AMD PCs use x64.

Windows x64 Windows ARM64
Installation steps

Save your documents, quit all three Office apps, extract the ZIP, and double-click Install.cmd. Start Office normally under the same Windows account. On the 三桥 AI ribbon, choose 打开侧边栏 for the task pane or 打开独立窗口 for a separate window.

Mac

Open About This Mac in the Apple menu. M-series Macs use the Apple silicon download.

Mac · Apple silicon Mac · Intel
Installation steps

Extract the ZIP and double-click Install.command. In the Word, Excel, or PowerPoint app menu, choose Services → 打开三桥 AI. macOS may request permission to control the selected Office app. To add the optional task pane, quit Office, run Enable-Embedded-Taskpane.command, and trust the local certificate when prompted. Reopen Office and select 三桥 AI（本机共享） under My Add-ins.

From selection to result

Download the illustrated user guide PowerPoint · 40 slides · English

  1. Connect a model

    In model settings, choose a provider or a local API. For a local API, start your model runtime first. Enter its model ID and base URL, such as http://127.0.0.1:8001/v1. Choose OpenAI Chat Completions or Claude (Anthropic Messages) to match your server, then select Connect and save.

  2. Choose context

    Read a Word or Excel selection, select PowerPoint slides, or choose a folder of reference files.

  3. Review the preview

    Review the text, formulas, tables, or slide changes. The selected model receives context when you request generation.

  4. Confirm the destination

    Check the document and location before applying. Read the selection again if the target has changed.

System and model requirements

Desktop Office
Perpetual editions are supported when the required capabilities are available. Use the Windows ribbon to open either the task pane or a separate window. On a Mac, open the separate window from Services, or use the optional pane from My Add-ins.
Installation and permissions
The standalone window and the Windows pane load their interface from the package. If Windows needs WebView2, run the offline WebView2 installer in the ZIP. The optional Mac pane uses a local HTTPS service and downloads Office.js from Microsoft.
Shared model profiles
The three apps use the same model profiles and OS credential vault for the current user. Your model runtime must already be running when using a local API.
Verification
Interactive Windows desktop Office acceptance is a manual check. See the project verification notes for the scope of package and feature testing.
